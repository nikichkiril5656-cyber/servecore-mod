# ServerCore — NeoForge 1.21.1

Серверный мод: **аукцион**, **навыки** (Бой, Добыча, Фермерство, Лесорубство, Рыбалка) и **питомцы** (5 редкостей, уровни 1–100) плюс простая экономика (баланс, переводы).

Весь интерфейс сделан на ванильных сундуках, поэтому клиентам мод ставить не нужно.

## Сборка

Требуется JDK 21.

```bash
# один раз: создать gradle wrapper (или скопируйте gradlew и папку gradle/ из официального NeoForge MDK 1.21.1)
gradle wrapper --gradle-version 8.10.2

./gradlew build
```

Готовый jar: `build/libs/servercore-1.0.0.jar`. Положите его в `mods/` сервера.

Если Gradle не находит `neo_version=21.1.172`, поставьте любую актуальную 21.1.x в `gradle.properties`
(список: https://projects.neoforged.net/neoforged/neoforge).

Тестовый запуск из исходников: `./gradlew runServer`.

## Команды

| Команда | Что делает |
|---|---|
| `/ah` (`/auction`) | открыть аукцион |
| `/ah sell <цена> [кол-во]` | выставить предмет из основной руки |
| `/ah my` | мои лоты (ЛКМ по лоту — снять) |
| `/ah claim` | забрать истёкшие/возвращённые предметы |
| `/balance` (`/bal`, `/money`) | баланс |
| `/pay <игрок> <сумма>` | перевод |
| `/skills` | меню навыков |
| `/pets` | коллекция питомцев |
| `/pets buy` | купить яйцо (случайный питомец) |

Для операторов (уровень 2):

| Команда | Что делает |
|---|---|
| `/eco give\|take\|set <игрок> <сумма>` | управление балансом |
| `/skills setlevel <игрок> <навык> <уровень>` | выставить уровень навыка |
| `/skills addxp <игрок> <навык> <опыт>` | выдать опыт |
| `/pets give <игрок> <тип> <редкость> [уровень]` | выдать питомца |

Навыки: `combat mining farming foraging fishing`.
Редкости: `common uncommon rare epic legendary`.
Питомцы: `wolf silverfish bee dolphin panda armadillo horse enderman warden`.

## Аукцион

- Лот живёт `durationHours` (по умолчанию 48 ч), затем предмет уходит в хранилище продавца.
- Покупка всегда через окно подтверждения.
- Налог с продажи (по умолчанию 5%) удаляется из экономики.
- Если инвентарь полон, предметы не теряются, а ждут в хранилище (`/ah claim`).
- Если продавец оффлайн, деньги зачисляются сразу, а при входе он видит сводку.
- Фильтры по категориям, 4 вида сортировки, постраничный просмотр.
- Чёрный список предметов и лимит лотов на игрока настраиваются.

## Навыки

| Навык | Опыт за | Бонус за уровень |
|---|---|---|
| Бой | убийство мобов (по макс. здоровью) | +0.5% урона |
| Добыча | руды и камень (нужен подходящий инструмент) | +1% скорости, +0.5% двойной дроп с руд |
| Фермерство | созревший урожай, адский нарост, арбузы, тыквы | +0.8% двойной урожай |
| Лесорубство | брёвна (топором) | +1% скорости, +0.8% двойной дроп |
| Рыбалка | улов | +0.8% двойной улов, монеты за каждый улов |

Максимум — 60 уровней (настраивается), за каждый новый уровень выдаётся награда монетами.
Блоки, которые поставил игрок, опыта не дают (защита от фарма; список хранится в памяти до перезапуска).

## Питомцы

- 9 типов, у каждого по 2 бонуса: атрибуты (урон, здоровье, броня, удача, скорость, скорость добычи) или бонус к опыту навыка.
- Редкость: Обычный, Необычный, Редкий, Эпический, Легендарный. Она задаёт множитель бонусов: x1.0, x1.15, x1.35, x1.6, x2.0.
- Уровни 1–100: на 1 уровне действует 20% бонусов, на 100 — все 100%.
- Активный питомец получает опыт вместе с навыками (доля `xpShare`).
- Источники: убийство враждебных мобов (у боссов шанс выше), рыбалка, `/pets buy`, админ-команда.
- ПКМ по питомцу в `/pets` превращает его в предмет (Сердце моря). Его можно продать на аукционе, а ПКМ по предмету добавляет питомца обратно в коллекцию.

## Конфигурация

`config/servercore-common.toml` (создаётся при первом запуске): валюта, стартовый баланс, налог, лимиты и цены аукциона, максимальный уровень навыка, множитель опыта, награды, шансы дропа питомцев, цена яйца.

Данные хранятся в `world/data/`: `servercore_players.dat` и `servercore_auction.dat`.

## Заметки

- Тексты (на русском) заданы прямо в коде; для перевода ищите строки в `menu/`, `command/` и `Fmt`.
- Если у вас много серверных модов с собственными GUI-сундуками, конфликтов быть не должно: меню используют ванильный `ChestMenu` и не пропускают ни одного клика.
